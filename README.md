# Python Test Repository

This repository is set up for testing Python code, automated CI/CD workflows, and Myco PR Reviewer agent integration.

## Project Structure
- `src/main.py`: Core application code
- `tests/test_main.py`: Unit tests using pytest
- `.github/workflows/myco.yml`: Myco automated PR review workflow
- `.github/workflows/python-test.yml`: Automated Python testing CI workflow
